An interactive, Python-based educational platform designed to help users master quantitative aptitude, logical reasoning, and data analysis. Built natively on **Streamlit** and **Plotly**.

## 🚀 Features
The app contains 8 fully fleshed-out learning modules, each featuring a **Concept Explorer**, a dynamic **Calculator Mode**, and an auto-generating **Practice Mode**.

1. **Clock Problems**: Analyze angles between hands, reflexes, overlap times, and perpendicular instances.
2. **Calendar Problems**: Odd days calculation, century rules, leap year logic, and date-to-weekday tools.
3. **Patterns & Figures**: Detect rules in Arithmetic, Geometric, Fibonacci, alternating series, and shape patterns.
4. **Tabular Data Interpretation**: Extract insights, compute growth, and average complex financial datasets.
5. **Bar Graph Analysis**: Interactive grouped and stacked bar chart comprehension.
6. **Pie Chart Analysis**: Math conversions between raw slices, percentages, and central degrees.
7. **Line Graph Analysis**: Trend detection, peaks, valleys, moving averages, and compound growth.
8. **Scatter Diagram Analysis**: Pearson correlation coefficient (r), linear regression (line of best fit), and interpretations.
9. **Result Summary & Mistake Analyzer**: Tracks your streak, accuracy, and weakest modules globally via session state, providing plain-English explanations for recent failures.

## 🛠️ Tech Stack
- **Python 3.10+**
- **Streamlit**: Core framework and UI state management.
- **Plotly**: For all interactive charts (Pie, Bar, Scatter, Line, and drawing analog clocks/shapes).
- **Pandas / Numpy / Scipy**: Fast mathematical regressions and dataframe manipulations.

## 💻 How to Run
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Launch the app:
   ```bash
   streamlit run app.py
   ```
3. Open `http://localhost:8501` in your browser.

## ✨ UI / UX
Fully supports Streamlit's native Light and Dark modes. Features customized CSS, floating cards, subtle hover states, drop-shadows, and responsive layouts that adapt dynamically to your screen.
